Browse redesign – v1

This prototype explores a more user-centred browse journey, replacing the system-led drill-down approach.

Purpose

Test whether users can successfully navigate and refine large result sets using filters and contextual information.

What is being tested

  • Right-hand filter panel
  • File path display and understanding
  • Result structure and metadata grouping

Design

This is a limited interactive prototype built in Axure RP.
